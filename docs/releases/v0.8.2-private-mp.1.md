Testing prerelease of Phira with private, host-supplied multiplayer charts.
All packages are built from the tagged source commit. Login/authentication is unchanged.

## Private sharing

Every player needs a compatible modified client and the matching modified MP server.
The host imports a chart into Local, joins a room and selects that chart.
The server relays the ZIP to room members without publishing it to the catalogue.
Charts are stored in server room memory while the room exists.

Received charts are cached under `mp-local/<SHA-256>` and are not added to the visible
Local library. There is no Save to Local. Identical archive bytes can reuse extracted
files, but clients still download the archive before looking up the cache, so selection
and readiness delays remain. Repacking can create another cache folder. Cache files
can persist after a match; there is no bounded eviction policy.

Limits: 32 MiB compressed, 128 MiB extracted, 4096 ZIP entries. Transfers use SHA-256 checks.
Normal upstream MP servers do not support this private transfer protocol.

## Important limitations

- **Official score uploads are unavailable in these public-source builds, including catalogue scores.** The closed official record/attestation implementation is absent. Use the official client for official scores and RKS. Private multiplayer scores are room-only and trust-based.
- Android is optimized but signed with an ephemeral test certificate. It uses the official package ID and cannot update installations signed with another key, including earlier test builds. Back up/export data before reinstalling, or use a separate Android user/profile. No signing secrets are included or needed.
- Windows is unsigned. Linux targets Ubuntu 24.04 x64, not every distribution; older glibc versions are unsupported by this package.
- Earlier private sharing and Windows–Android crossplay were user-tested. This release runs build/tests, package checks, Linux client startup under a virtual display and a server listening-port check. These are not complete gameplay tests. Linux gameplay/crossplay, real audio, disconnect recovery and all device configurations remain unverified.

Source archives include the public client and modified `vendor/phira-mp` server.
They do not include closed official code or signing keys. Builds download external
dependencies and checksum-pinned upstream assets; Android also downloads the upstream APK shell.
